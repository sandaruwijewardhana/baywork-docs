# BayWork Founder — Full-Stack Course Materials

Actual study materials for the 3-month plan in [`../fullstack-learning-plan.md`](../fullstack-learning-plan.md).
Built **for a hard full-stack interview** — rigorous, first-principles, self-test heavy.

## Structure

```
learning/
  week-01-foundations/
    01-how-the-web-works/
      notes.md       ← comprehensive teaching notes (read + understand)
      exercises.md   ← hands-on + written exercises (DO these, no AI)
      self-test.md   ← interview-style questions + answer key (grade yourself)
    02-...            (added as you progress)
```

## How to study each topic (the loop)

1. **Read `notes.md`** slowly. Stop at every term you can't explain and look it up.
2. **Do every exercise in `exercises.md`** by hand — no copy-paste, no AI.
3. **Take `self-test.md` closed-book.** Write/say your answers *before* looking at the answer key.
4. **Score yourself.** Any question you miss → re-read that part of the notes, retry the next day.
5. **Teach-back:** explain the whole topic out loud as if to another person. If you stumble, you're not done.

> Rule: you only "pass" a topic when you can answer every self-test question cold and explain it out loud.
