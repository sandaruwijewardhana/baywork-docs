## How to use these
1. Read the explainer top to bottom — it teaches every theory the code uses.
2. Close it. Open a **blank file** and try to write `auth.ts` from memory.
3. Compare against the real file. Note what you missed → re-read that section.
4. Repeat until you can reproduce it cold and explain every line out loud.

> These assume you've done the foundations (JS core, async/await, TypeScript basics, Node/Express) from
> `../../fullstack-learning-plan.md`. Each theory is still re-explained inline, but the more of those you've
> done, the smoother this reads.
